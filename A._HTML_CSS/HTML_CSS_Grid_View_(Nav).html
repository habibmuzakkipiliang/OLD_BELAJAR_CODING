Golang atau Go Language (kini disebut Go) adalah bahasa pemrograman yang diciptakan dan dikembangkan oleh Google. Para developer software dapat menggunakan Golang untuk mengembangkan aplikasi, website, hingga layanan cloud. Dilansir situs Tech Target, Google secara resmi merilis Golang pada tahun 2009. Perusahaan asal AS itu tidak bekerja sendiri dalam menciptakan Golang, melainkan bekerja sama dengan tiga orang lainnya, yakni Robert Griesemer, Ken Thompson, dan Rob Pike.
